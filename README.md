## 📂 Projetos em Destaque

Confira alguns dos projetos que desenvolvi para resolver problemas reais e aprimorar minhas habilidades:

### ✈️ Travelgram
> *Rede social onde as pessoas mostram os registros de suas viagens pelo mundo.*
Uma interface imersiva para amantes de viagens compartilharem suas experiências.

### 🍽️ Food Explorer
> *Aplicação para explorar pratos de um restaurante, realizar pedidos e gerenciar o cardápio.*
